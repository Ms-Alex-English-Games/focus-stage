# Focus Stage by Ms AlexV_englishprojects™

A free K-pop dance-battle **noise meter + timer** for the start of a lesson (e.g. after recess). The quieter the class, the tighter the crew dances; loud voices make the rival crew win. The last 5 seconds play a short K-pop style tune.

## Use in class
1. Open the page on your classroom screen and click **Mic** (allow the microphone).
2. Set **Sensitivity** for your room, pick the timer length, choose Bar or Hourglass, press **Start**.
3. Use **Test tune** and **Tune volume** to set the final tune level before the lesson.

Microphone audio is only measured for loudness on the device. It is never recorded or sent anywhere.

## Put it online (GitHub Pages)
1. Create a repo named `focus-stage` under `Ms-Alex-English-Games`.
2. Upload `index.html`, `og-image.png` and this `README.md` to the repo root.
3. Repo **Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save**.
4. After about a minute it is live at `https://ms-alex-english-games.github.io/focus-stage/`.
